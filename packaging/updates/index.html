A native workspace for AI coding agents.

Run several agents in isolated Git worktrees. Plan, edit, and review their changes in one macOS app.

Download for macOS

Apple Silicon · Apple-notarized · Apache 2.0

From a task to reviewed changes

Give each task a worktree

Launch Claude Code, Codex, OpenCode, or a shell. Keep terminals and worktrees together as you switch between local projects and Linux projects over SSH.

Build a pipeline

Assign agents and models per stage, group reviews in parallel, and limit a reviewer to paths it owns. Start by typing or dictating a task.

Review the evidence

Inspect diffs, test results, and acceptance criteria. Send line feedback back to the right developer, then open a pull or merge request for the changes you accept.

Inside the workspace

Search and edit project files, compare and stage changes, and create another isolated worktree when you need it.
