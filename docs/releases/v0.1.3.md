# Hive 0.1.3 — Files, previews, and agent workflows

This release includes all changes on `main` since 0.1.2, plus image previews,
automatic file saving, and reopening the workspace from the Dock.

## What's new

- Browse, search, create, rename, move, and delete files in the Files navigator.
- Edit source files in native tabs with conflict detection, recovery, and JS/TS import navigation.
- Preview SVG, PNG, JPEG, WebP, GIF, BMP, TIFF, and ICO in file tabs. SVG offers Preview and Code modes; animated or multi-page formats show their first frame/page.
- Save dirty files when focus leaves the editor and before closing. This is enabled by default and can be disabled in Settings → Files. Failed writes and conflicts retain the close confirmation.
- Reopen the main workspace from the Dock after closing its last window.
- Use agent activity and attention indicators, launch/resume workflows, and Git-error handoff drafts. OpenCode supports commit-message generation and session resume.
- Faster file search and diff rendering, improved file-operation recovery, versioned settings, and assorted terminal, dialog, and tab-bar fixes.

## Compatibility and limits

- macOS on Apple Silicon only. Existing settings and file tabs load without manual migration.
- Image previews are static, without zoom; raster images are read-only. SVG external resources are omitted and resource limits are enforced.
- Reopened terminals start fresh shells; restoring layout does not replay commands or resume running processes.
