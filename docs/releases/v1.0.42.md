# Hive 1.0.42 — TypeScript, React and Rust editing

Select a TypeScript component or a Rust type from completions to insert its name and import together. One Undo removes both. Signature help highlights the active parameter. Use F8 and Shift-F8 to visit diagnostics, and ⌘. to apply a quick fix in the current file.

- Press ⌘D to select the next occurrence, ⌘/ to toggle a comment, ⌥↑/↓ to move lines, and ⌥⇧↑/↓ to duplicate them. The command palette (⌘⇧P) shows shortcuts for the current context.
- Jump to a line and column with ⌃G, enter a file location in ⌘P, or ⌘-click a compiler location in a terminal. Each terminal opens files in its own worktree. ⌃Tab switches recent tabs and ⌘⇧T reopens a closed file at its cursor.
- Search unsaved buffers in a local worktree or use Find in Folder. ⌘⌥O searches symbols from active language servers. F2 previews a semantic rename by file and checks for concurrent changes before updating the open buffers.
- See cursor position, choose the indentation for an open file, and jump between Git changes with ⌥F5 and ⌥⇧F5.
