# Hive 1.0.36 — OpenAI transcription and pipeline drafts

## What's new

- Dictate a task with OpenAI's `gpt-transcribe`. Select it in Settings → Pipelines → Dictation if your OpenAI account lists the model. Choose a language or let OpenAI detect it, and use the prompt to supply project names and technical terms.
- Reopen a saved run from the Drafts section in the project's pipeline library.
- Hive now shows **Needs you** when a local Claude Code session appears to be waiting at a startup prompt, such as a request to trust a new worktree.
- Pipeline stages now pass the task prompt separately from additional folders when launching Claude Code or Antigravity. This fixes launches where a task with images or extra worktrees was mistaken for a folder path.
- The default Developer prompt includes guidance on module boundaries, data ownership, failure handling, and using the Ponytail skill when available.

## Verification

Local HTTP tests cover the original WAV upload, language selection and detection, empty transcripts, and retries after provider errors. The dictation settings were checked in a native macOS build.

Live transcription with a provider key, a paid Claude Code session, and installing the update through a full Sparkle relaunch remain unverified.
