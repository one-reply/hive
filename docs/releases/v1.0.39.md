# Hive 1.0.39 — Clearer pipeline acceptance

## What's new

- Acceptance puts unresolved criteria first, shows two by default, and displays how many are resolved. Each criterion shows its evidence status. A reviewer assessment stays open until you verify it or accept an exception.
- Reviewer notes expand alongside the criteria in a scrollable panel. **Accept changes** stays visible, with the reason beside it whenever acceptance is blocked.
- The **Changed files** actions use icons alongside their labels.

## Verification

Local formatting, Clippy, packaging tests, and the `hive-core` dependency check passed. A complete Sparkle update and relaunch is outside the scope of these checks.
