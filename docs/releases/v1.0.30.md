# Hive 1.0.30 — Pipeline acceptance fixes and a new app icon

## What's new

- Hive’s new H uses 27 whole honeycomb cells. It appears in the Dock and on the welcome screen, with black cells on white in the light app icon and white cells on black in the dark icon.
- **Resume draft** brings back the launch form you edited for a project. Quick start is available when a single repository lane receives every review, and the launch preview reflects the steps that will run.
- At acceptance, Hive keeps queued line comments until you send or remove them. A task-wide **Request changes** includes the relevant queued comments. Criterion evidence now matches numbered lists and checkboxes.
- Delivery checks the publishing remote and reviewed commit. A merged request can be found again after restart, and a closed, unmerged request leaves the branch available for a new one.

## Verification

The release source passed 1,170 Rust tests, Clippy and 26 packaging tests. Three Rust tests were marked ignored. The icon export check covered both appearances, all 20 PNG sizes and both ICNS files.

A full pipeline run with paid agents and an end-to-end Sparkle installation and relaunch were outside this test pass.
