# Hive 0.1.9 — Quicker project setup and clearer controls

## What's new

- Add Project now offers local folders, SSH aliases from your OpenSSH config and hosts already used by your projects. Pick a known host to connect immediately, or expand Another SSH host to enter a new target.
- Hive Light and Hive Dark keep primary button labels readable. Hive Dark also improves input borders, selected controls and the sidebar background.
- Appearance uses smaller palette cards, and the default CLI agent picker shows each agent's logo.
- Files search uses the standard input size. Git comparisons show short branch names and a clearer commits-only label.

## Installation and compatibility

- macOS on Apple Silicon only; Intel Macs are unsupported.
- Update through Hive → Check for Updates, or download the signed archive attached to this release.
- Existing projects, workspaces and settings remain compatible. SSH authentication and connection settings continue to be handled by OpenSSH.
- SSH suggestions support concrete aliases and simple file-name wildcards in Include paths; manual entry remains available for other configurations.
- Finish active agent sessions before installing an update that restarts Hive.
