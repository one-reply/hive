# Hive 1.0.41 — Click file links in Codex

Click a file reference in a Codex conversation to open its source at the referenced line in the Codex side panel. A single click works without holding Command. Dragging across the text still selects it for copying.

Web links continue to open in the default browser.

Verified in a native Hive window with Codex CLI 0.172.0 on macOS.
