# Hive 0.1.11 — Less work per terminal frame

## What's new

- Busy terminals use less CPU: plain characters share a drawing layer, and terminal output no longer rebuilds the Sidebar, Git and Files panels on every frame.
- Terminal updates follow the display refresh without an extra 16 ms throttle.
- The update notification is now a compact version announcement with a link to that version's release notes. Settings → Updates links to the release history.

## Installation and compatibility

- macOS on Apple Silicon only; Intel Macs are unsupported.
- Update through Hive → Check for Updates, or download the signed archive attached to this release.
- Existing projects, workspaces and settings remain compatible.
- Finish active agent sessions before installing an update that restarts Hive.

## Verification

The rendering changes were measured locally against 0.1.10 with isolated fixture projects:
CPU fell from 5.1% to 1.8% with one redrawing terminal and from 10.5% to 3.6% with four.
A terminal fixture covering styles, colours, CJK, emoji, decorations and cursor rendering
matched Menlo pixel for pixel. JetBrains Mono differed by at most 2/255 in 308 edge pixels
where filled characters and borders overlap. The cached Git panel added and removed a
new untracked file correctly. These are local measurements, not performance guarantees.

Automated tests cover decorated versus plain glyph selection and the installed-version
release URL, alongside the existing terminal and state regression tests. Build, signing
and distribution checks are recorded below when the release artifacts are verified.
