# Hive 1.0.33 — Pipeline prompts and quieter code references

## What's new

- New Pipelines libraries start with four built-in prompts for planning, development, QA, and security and performance review. Quick fix and Cross-repository reuse these roles. Existing prompt libraries keep their saved prompts.
- Press **⌘⇧C** in the editor or in a diff to copy a line reference for an agent. Hive shows a notification only if it cannot create the reference.

## Verification

CI checks formatting, Clippy, workspace tests, licenses, and both Linux helpers before packaging the Apple Silicon build. Release verification covers Developer ID, Apple notarization, Gatekeeper, the archive checksum, and both Sparkle signatures.

Full Sparkle installation and relaunch and paid-agent pipeline runs are outside this release's test scope.
