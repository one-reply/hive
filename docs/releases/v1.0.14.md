# Hive 1.0.14 — Smoother project actions

## What's new

- The project menu, new-worktree button, and collapse arrow now fade in and out together when you hover over the project header. Their space stays reserved, so the project name does not shift.
- The arrow smoothly rotates between expanded and collapsed states over 200 ms, using the same easing and duration as the worktree list. Reduced Motion is respected.
- Keyboard focus in the project header or its buttons reveals the whole action group. The group also stays visible while its menu is open.

Linux helper CI now uses the UC Berkeley OCF HTTPS mirror of Ubuntu after repeated runner DNS failures. Ubuntu's existing signing keys and all build/test gates remain enabled.

Stable release for macOS on Apple Silicon. Existing settings and workspaces remain compatible; no migration is required.

## Verification and limits

Formatting, Clippy with warnings denied, 681 Rust tests, 26 Python tests, dependency/license checks, secret scans, and the core/GPUI boundary passed. Three existing opt-in Rust tests remain ignored. Existing GPUI regressions continue to cover project selection, folding, and keyboard activation.

An isolated debug app with disposable Git projects verified that all three controls appear together, disappear together, and continue to fold worktrees without switching projects. Native intermediate animation frames, Reduced Motion, keyboard-focus visibility, menu retention, clean-account installation, macOS 12 runtime, Keychain allow/deny, and a full Sparkle download/install/relaunch were not rechecked for this release.
