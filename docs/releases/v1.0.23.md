# Hive 1.0.23 — Editor navigation and language tools

## What's new

- Navigate code with file and symbol breadcrumbs, Go to Symbol, Back/Forward history, Peek Definition, references, and sticky scope headers.
- Use installed Rust and TypeScript language tools for completion, hover, definitions, references, and diagnostics. The global Language tools setting is enabled by default; preview tabs wait until pinned. These tools may execute project-controlled code, so disable the setting before opening untrusted worktrees. Hive does not install tools automatically.
- Format documents with rustfmt or Prettier, with stale-result protection and a single Undo step. Prepare an agent request from the selected code and its file context.
- Review Problems, references, and content-search matches in contextual excerpts. Mark Reviewed now tracks the exact diff revision.
- Find files with more precise filename matching, and use Reveal from breadcrumbs or the Files menu even when a search filter is active.
- Keep diagnostics visible after unrelated edits and navigation targets below sticky headers. Diagnostic Markdown is sanitized in the background and only web links are allowed.
- Improve SSH command handling across login shells and banners, preserve terminal Ctrl+- input, and fix a process-cancellation race.

## Verification and limits

The regression pass completed 923 workspace tests (3 existing opt-in tests ignored), 236 remote-helper tests on macOS (1 existing opt-in test ignored), and 26 Python tests. Formatting, Clippy with warnings denied, the workspace build, and the GPUI-free hive-core dependency boundary passed. Fifteen additional tests cover the final regression fixes; reverting each fix reproduces a test failure. Release CI also checks security and licenses, both Linux helper architectures, and the macOS bundle.

Native macOS testing in disposable profiles covered editor navigation, rust-analyzer diagnostics, formatting/Undo/Save, dirty-document close guards, Peek and references, Problems, Files filtering and Reveal, SVG preview, terminal input and splits, Git hunk staging/unstaging, Reviewed invalidation, and worktree creation. The final fix pass rechecked diagnostics after an unrelated unsaved edit, upward navigation under sticky headers, and filtered/root Reveal.

Distribution requires Developer ID signing, Apple notarization, a stapled ticket, Gatekeeper acceptance, verified Sparkle archive/feed signatures, and downloaded-asset verification. The maintainer's installed Hive is not replaced.

A clean macOS account, minimum macOS version, live SSH sessions, Keychain denial, and a complete Sparkle install/relaunch were not reverified. TypeScript/Prettier were not rerun in the final fix pass; captured server samples and hermetic tests cover the changed paths. Release frame-time measurements and a full folded/wrapped navigation stress matrix were not run.
