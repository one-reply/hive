# Hive 1.0.8 — Resolve Git conflicts in Hive

## What's new

- Open a file from Conflicts in the Git panel to resolve it in place. Choose Current, Incoming or Both for each block, undo a choice, accept all remaining blocks, and move between unresolved conflicts. Mark Resolved writes your choices and stages the file.
- The Git panel shows unfinished merges, rebases, cherry-picks and reverts, with Continue and confirmed Abort actions. Continue stays disabled until every file is resolved.
- Take a whole file from either side, including delete/modify conflicts, with confirmation before replacing or deleting it. Resolve with Agent prepares a draft for your worktree's agent without sending it.
- Conflicted files opened through Show changes reach the resolver instead of the unsupported combined-diff error. Files edited elsewhere after loading are reloaded without overwriting those edits; BOM and line endings are preserved.

Stable release for macOS on Apple Silicon. Existing settings and workspaces remain compatible; no migration is required.

## Verification and limits

Local formatting, Clippy with warnings denied, 581 Rust tests, 26 Python tests, and the core/GPUI boundary passed. Three existing opt-in tests remain outside the default suite.

Automated checks cover conflict status parsing, operation detection, whole-file choices and literal paths, abort/continue behavior, multi-commit rebase conflicts, stale-file protection, saved settings compatibility, BOM/CRLF preservation, widget resolutions, navigation and toolbar state.

Not repeated: clean-account installation, macOS 12 runtime, a full Sparkle install/relaunch, Keychain allow/deny, and live SSH conflict resolution. Empty replayed commits can still require Git's skip action in the terminal. Finish active agent sessions before an update restarts Hive.
