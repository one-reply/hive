# Hive 1.0.46 — Inline dependency upgrades

## What's new

- Apply an available dependency upgrade directly from its hint in `package.json`. Each upgrade is one undoable edit, and known advisories are available beside the dependency.
- Toggle dependency hints from the package toolbar, with ⌘⌥V, or in Settings → Files. The package toolbar menu gives you Refresh, Sort, and Install on save.
- Files refreshes only visible, expanded folders. The Git refresh indicator stays quiet during routine background polling.
