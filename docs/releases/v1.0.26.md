# Hive 1.0.26 — Visual agent pipelines

## What's new

- Open **Pipelines** from the status bar or **View → Toggle Pipelines**. Start from a reusable workflow, choose your local repositories and base branches, and approve the planner’s assignments before development starts.
- Give each stage its own agent and model. Development can run in parallel across repositories, with dedicated task worktrees and a timeline showing activity, elapsed time, and requests for input or approval.
- Review diffs, agent reports, and required checks in one place. QA can send findings back to the relevant development lane, and Hive keeps each run’s checkpoints and worktrees available for review and follow-up.
- Open web links in the terminal with a click. Drag across a link to select text.

## Verification

Automated checks cover scoped agent reports, checkpoint persistence and recovery, worktree preparation, and rerunning QA when reviewed files change. Native pipeline QA used disposable repositories and a controlled CLI to exercise planning, parallel development, a QA repair cycle, and acceptance. See [PR #105](https://github.com/one-reply/hive/pull/105) for the feature verification.

A clean macOS account, minimum macOS version, Keychain denial, and a full Sparkle update and relaunch were outside this verification pass.
