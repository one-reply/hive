# Hive 1.0.19 — Conversation history and a smaller app

## What's new

- Search a worktree's Claude Code and Codex conversation history with ⌘⇧H and resume a conversation in a terminal. Conversations already running in Hive open their existing tile.
- Keep your Mac awake while agents work, with a status-bar indicator and a setting to turn it off.
- Choose a new branch's starting point from a searchable list. Local and remote branches remain distinct even when a tag has the same name.
- Stop a long-running Git operation from the app. Git mutations now allow up to 15 minutes before their deadline.
- Safer terminal paste filters control sequences that could escape bracketed paste. Pasted images use the same size limits as image previews.
- Improved SSH terminal command quoting for non-POSIX login shells, bounded agent API connections and wait times, and fewer state writes while typing in the editor.
- Smaller Apple Silicon downloads and app bundles. C#, Kotlin, Scala, and Swift files now open as plain text; the other 31 syntax grammars remain available.
- Added icons to project and worktree menu items.

## Verification and limits

Release checks cover formatting, Clippy with warnings denied, workspace tests, Python packaging tests, security and licenses, Linux helpers for both architectures, and the GPUI-free hive-core boundary. Distribution requires Developer ID signing, Apple notarization, a stapled ticket, Gatekeeper acceptance, verified Sparkle signatures, and downloaded-asset verification.

Regression coverage includes branch/tag name collisions, terminal paste sanitization, SSH command quoting, agent API limits, editor snapshot changes, Git cancellation and deadlines, conversation parsing, and keep-awake transitions. Native release smoke results are recorded when the final bundle is prepared.

Live SSH with fish/csh, live agent Resume, a clean macOS account, the minimum macOS version, and a complete Sparkle install/relaunch are not reverified for this release. Keep-awake behavior is covered by deterministic GPUI tests; real idle sleep is not exercised. The maintainer's existing Hive installation is not replaced during verification.
