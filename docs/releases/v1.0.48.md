# Hive 1.0.48 — Worktree tabs and Git conflict navigation

## What's new

- When you switch back to a project or worktree, Hive focuses the last tab you used there if it is still open. This works with terminals, files, diffs and conflict tabs during the current session.
- The Git conflict toolbar shows how many conflicts remain and displays your position once you navigate between them. After you resolve the last conflict marker, the toolbar hides the conflict navigation and keeps the whole-file actions.

The worktree tab behavior was checked on macOS in an isolated profile by switching between two projects and between linked worktrees, then checking the restored tab and keyboard focus.
