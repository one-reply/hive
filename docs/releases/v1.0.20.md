# Hive 1.0.20 — Clearer project navigation

## What's new

- Selecting an inactive project now expands its worktrees automatically. Other projects keep their expanded or collapsed state.
- Click the active project's name to collapse or expand it without changing the selected worktree. Enter and Space support the same action.
- The active project's menu, new-worktree button, and disclosure arrow stay visible without hovering, making the current project easier to identify.

## Verification and limits

Release checks cover formatting, Clippy with warnings denied, workspace tests, Python packaging tests, security and licenses, Linux helpers for both architectures, and the GPUI-free hive-core boundary. Distribution requires Developer ID signing, Apple notarization, a stapled ticket, Gatekeeper acceptance, verified Sparkle signatures, and downloaded-asset verification.

The GPUI regression test covers project selection and expansion, repeated header clicks, preservation of the active worktree and other projects' expansion, independent disclosure controls, Enter/Space, and persisted expansion. Native macOS verification in an isolated debug profile covered these interactions, controls without hover, project menus and the new-worktree dialog, drag-and-drop, and restoration after Quit/relaunch without a panic.

A clean macOS account, the minimum macOS version, live SSH sessions, and a complete Sparkle install/relaunch are not reverified for this patch. The maintainer's existing Hive installation is not replaced during verification. This release changes no persisted format and adds no dependencies.
