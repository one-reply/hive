# Hive 1.0.37 — Code review before QA

## What's new

- **Feature delivery** and **Cross-repository** now run a dedicated **Code review** stage before QA. You can add the same stage to **Quick fix** in the workflow editor.
- The default reviewer traces changed behavior through its callers and checks whether passing tests would catch a specific defect. Each finding includes the affected code, the scenario, and a check to verify the fix.
- Existing libraries with the original built-in reviewer text pick up the new instructions. Saved custom prompts and in-progress runs keep their instructions.

## Verification

A full Feature delivery run with Codex CLI confirmed that Code review completed before QA started. Separate read-only Codex CLI runs with the updated prompt found a pagination defect missed by three passing tests, then confirmed the repaired behavior.

Full Sparkle install and relaunch were outside these feature checks.
