# Hive 1.0.34 — Pipeline dictation and run overview

## What's new

- Dictate a task from the New run form. In Settings → Pipelines, choose an audio-capable model, set a transcription language, and customize the prompt. The recording panel shows input levels as you speak.
- Hover over the Pipelines counters in the status bar to see runs and drafts across projects. Save a draft and close the form to return to it later.
- Choose a permission mode for each agent stage. Rename stages directly in the wider inspector and open the prompt library from the Pipelines panel.

## Verification

The release checks cover formatting, Clippy, workspace tests, licenses, both Linux helpers, and Apple Silicon packaging. Distribution verification covers Developer ID, Apple notarization, Gatekeeper, the archive checksum, and both Sparkle signatures.

Live provider transcription, paid-agent runs, and a full Sparkle installation and relaunch are outside this release's test scope.
