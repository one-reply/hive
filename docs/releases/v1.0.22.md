# Hive 1.0.22 — Clearer sidebar and Git history

## What's new

- Changes, Compare, and History show a pointer cursor and smooth, rounded hover feedback with space around their labels.
- Git and Files use the same compact hover buttons as the sidebar toggle, keeping the header visually consistent.
- Commit history distinguishes hashes, authors, and dates with the active theme's colors. The opened commit has a tinted card and accent border.

## Verification and limits

Release checks cover formatting, Clippy with warnings denied, 806 passing Rust tests (3 opt-in tests ignored), Python packaging tests, security and licenses, Linux helpers for both architectures, and the GPUI-free hive-core boundary. Distribution requires Developer ID signing, Apple notarization, a stapled ticket, Gatekeeper acceptance, verified Sparkle signatures, and downloaded-asset verification.

Native macOS checks in an isolated debug profile verified Git/Files hover and switching, padded text-tab layout, colored history metadata, and opening a commit. All new colors use the active theme; light-theme contrast and text-tab mouse hover were not manually reverified because of intermittent UI automation failures.

A clean macOS account, minimum macOS version, live SSH, Keychain denial, and a complete Sparkle install/relaunch were not reverified for this visual update. The maintainer's installed Hive is not replaced. No dependencies or persisted formats changed.
