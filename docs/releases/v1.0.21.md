# Hive 1.0.21 — Agent tools and accurate usage

## What's new

- Hive launches Codex and Claude with pane-specific MCP tools for listing, starting, messaging, reading, waiting for, and interrupting sibling agents. Tool identity stays attached to the originating pane without changing global agent configuration or permissions. OpenCode and Antigravity retain the documented Hive CLI fallback.
- GitHub sign-in recognizes the current GitHub CLI device-code output and opens the authorization page in your browser once the complete URL is available. Cancelled sign-in attempts cannot reopen the page.
- Antigravity usage now reads the CLI's structured `/usage` report, including Gemini pools. An exhausted Gemini quota is no longer hidden by an unused Claude/GPT pool. Background checks have a deadline and block browser launchers and CLI auto-updates.

## Verification and limits

Release checks cover formatting, Clippy with warnings denied, workspace tests, Python packaging tests, security and licenses, Linux helpers for both architectures, and the GPUI-free hive-core boundary. Distribution requires Developer ID signing, Apple notarization, a stapled ticket, Gatekeeper acceptance, verified Sparkle signatures, and downloaded-asset verification.

Regression tests cover the captured GitHub CLI output, partial and invalid device prompts, opening once and ignoring cancelled callbacks; captured Antigravity usage including zero remaining, malformed reports, disabled pools and browser-launch suppression; and MCP discovery, transport, routing and failures. Native macOS testing in an isolated debug profile confirmed the exhausted Antigravity quota appears as 0% remaining. Two simultaneous Codex and Claude clients discovered their pane-specific tools while retaining other MCP servers.

A real model-issued MCP call, resuming an old agent conversation, a completed GitHub OAuth grant, live SSH, a clean macOS account, the minimum macOS version, and a complete Sparkle install/relaunch are not reverified for this release. Antigravity may return CLI-cached quota data; missing or malformed data is reported as unavailable. Automatic MCP setup requires supported Codex/Claude CLI flags; OpenCode and Antigravity do not receive automatic MCP configuration. The maintainer's installed Hive is not replaced during verification. No persisted format changes; the official Rust MCP SDK is added at the app boundary.
