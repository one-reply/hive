# Hive 1.0.27 — Reusable pipeline prompts and branch selection

## What's new

- Create reusable stage prompts in **Settings → Pipelines**. Link them from workflow stages, update linked templates from one place, or customize a stage's instructions independently. Existing runs retain their original instructions.
- Choose an existing local branch for each repository when starting a run, or create a branch from a selected base. The form shows which checks are available for that revision and why planning is blocked when required inputs are missing.
- See at a glance whether a run is working, waiting for you, failed, completed, or cancelled. The updated run header and stage inspector put details and next actions closer to the relevant stage.
- Starter workflows have updated stage instructions. Hover animations preserve the intended colors in light and dark themes.

## Verification

Regression tests cover prompt links and migration, branch selection and stale branches, run status, and hover color interpolation. In a macOS debug build with disposable data, Hive opened the test repository, showed its checked-out branch, let us choose a new branch with a proposed base, and saved a reusable prompt.

A clean macOS account, the minimum supported macOS version, Keychain denial, and a full Sparkle install and relaunch were outside this verification pass.
