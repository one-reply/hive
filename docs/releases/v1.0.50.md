# Hive 1.0.50 — Keyboard-friendly dialogs and smoother workspace navigation

## What's new

- Start from the welcome screen, switch between the labeled Git and Files tabs, and expand or collapse projects and worktrees with smooth transitions that respect Reduce Motion.
- In Add project, press Enter to open the macOS folder picker. Tab through SSH hosts to bring each one into view, or choose Another SSH host to type an address.
- Type a task name and press Enter to create a worktree and start its terminal or agent. If creation fails, the dialog keeps your input. When tracking a remote branch, type to replace its suggested name.
- Standard Cancel buttons now cancel when focused and activated with Enter. Save and other safe defaults show a return symbol. Release packaging also checks that Sparkle's installer window resources are present in the signed app.

On Apple Silicon, we checked the workspace in light and dark themes and used the native dialogs to open the folder picker, create a worktree with a terminal, and switch to a new branch. Window tests cover keyboard focus, long SSH lists, empty names, and failed submissions. The SSH chooser was exercised without a live SSH connection.
