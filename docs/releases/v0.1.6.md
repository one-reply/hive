# Hive 0.1.6 — Linux projects over SSH

## What's new

- Add a Linux project through Add Project → Through SSH, using an alias such as `home` or `user@host`, then choose its folder. Remote projects appear alongside local projects with their host label.
- Browse, search, edit, preview, create, rename, move, and delete remote files. Unsaved recovery drafts stay on your Mac; saves preserve file formatting and detect conflicting edits.
- Run terminal tabs and splits, Git, worktrees, and Create & Start on your Linux machine. Hive uses your existing SSH configuration and automatically installs a small verified file helper for x86_64 or arm64, without sudo or Rust on the host.
- Keep local and remote projects with identical paths separate, including their settings, tabs, and restored workspaces. A failed scan keeps the last known worktrees and offers Retry.
- See disconnected SSH terminals clearly and open a new session explicitly. Interrupted writes require a state check before retrying, protecting against hidden repeated writes.
- Rename files with Enter while editing their name, and open distinct non-UTF-8 Unix filenames without tree-selection collisions.

## Installation and compatibility

- macOS on Apple Silicon only; Intel Macs are unsupported.
- Update through Hive → Check for Updates, or download the signed archive attached to this release.
- Existing local projects, settings, workspace layouts, and recovery drafts remain compatible.
- Linux hosts need SSH key access, Git, and `sha256sum`. First connect in a regular terminal to accept the host key and unlock your SSH key if necessary.
- Install and authenticate agent CLIs on the Linux host separately. Hive does not transfer Mac credentials or local agent hooks.
- Finish active agent sessions before installing an update that restarts Hive.

## Remote session limits

- SSH sessions do not use tmux. Agent continuity after a connection loss is not guaranteed; Hive never silently restarts an agent.
- Remote activity/approval tracking and conversation Resume are unavailable. Restored terminal tiles offer a new SSH session.
- Password entry inside Hive, local file or clipboard-image uploads, and port forwarding are not included.
- Creating or removing Git worktrees currently requires UTF-8 paths. Remote file operations preserve arbitrary Unix path bytes.
- Git commands have deadlines, but an already running command may continue until its deadline after its UI task is cancelled. Interrupted mutations are not automatically replayed.

## Verification

The published release records its exact build commit, CI results, signature and
notarization checks, and any unverified installation scenarios below. Native SSH
smoke testing covered adding a project, file operations, search, editing, image
preview, terminal splits, worktree creation, restart, and non-UTF-8 filenames on an
x86_64 Linux host. A real agent launch and a disconnect precisely during Save were
not exercised interactively; failure and conflict handling have hermetic tests.
