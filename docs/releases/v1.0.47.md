# Hive 1.0.47 — Side-by-side Git conflict resolution

## What's new

- See both sides of a Git conflict at once. The current branch is on the left, the incoming change is on the right, and the center pane shows what you will save.
- Take either side of a conflict, combine both in your preferred order, or edit the result by hand. You can undo a choice before marking the file resolved.
- Move between conflicted files while keeping your choices. Once every file is resolved, continue the Git operation from Hive.

On macOS, a two-file merge was completed in Hive and the resulting files were checked byte for byte. This manual check used a local repository.
