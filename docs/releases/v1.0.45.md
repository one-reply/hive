# Hive 1.0.45 — Dependency updates in package.json

Open a package.json in Hive to see available updates beside each dependency. Click a hint or press ⌘⌥V to compare the newest version in your declared range with the registry’s latest release. The menu previews the exact change and supports Undo.

- See OSV advisories for the version pinned in your workspace lockfile. Hive reads npm, pnpm, Yarn Classic, Yarn Berry and Bun lockfiles.
- Sort dependencies within their groups while preserving the rest of the file.
- Enable **Install on save** for an individual project to run its package manager after a successful save. It is off by default.
