# Hive 1.0.10 — Subtler terminal pane focus

## What's new

- The focused terminal pane now glows only 4 px inward from its edges, down from 18 px, keeping the highlight close to the border.

Stable release for macOS on Apple Silicon. Existing settings and workspaces remain compatible; no migration is required.

## Verification and limits

Formatting, Clippy with warnings denied, Rust and Python tests, the core/GPUI dependency boundary, and CI dependency, license and secret checks are required before publication. The 4 px glow was tuned on screen in the preceding change; this release changes only that visual constant and the version metadata.

Not repeated for this patch: clean-account installation, macOS 12 runtime, Keychain allow/deny, and a full Sparkle install/relaunch. Finish active agent sessions before an update restarts Hive.
