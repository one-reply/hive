# Hive 1.0.0 — First stable release

## What's new

- Hive's first stable release brings projects and Git worktrees, terminal agents, the native editor, Git review, SSH Linux projects, and signed in-app updates into one workspace.
- Code completion suggests names and members from the open file while you type. JavaScript and TypeScript editors also suggest import paths and named exports, reusing the existing import-navigation rules.
- Suggestions use a background index without starting a language server. Use Control-Space to open them manually, or turn off **Code completion** in **Settings → Files**. The shortcut can be reassigned.
- Includes the terminal rendering and background-work improvements from 0.1.11.

## Installation and compatibility

- macOS on Apple Silicon only; Intel Macs are unsupported.
- Update through **Hive → Check for Updates**, or download the signed archive and SHA-256 checksum attached to this release.
- Existing projects, workspaces and settings remain compatible. Code completion defaults to enabled when loading older settings.
- Finish active agent sessions before installing an update that restarts Hive.

## Completion scope

Suggestions are based on names in the current file, not inferred types or project-wide scope. They do not add imports automatically. Import aliases, package names and named exports are supported in local JS/TS projects; SSH projects support relative import paths.

## Verification

Automated coverage includes completion context and replacement ranges, Unicode names, comments and strings, import paths and exports, older settings, and editor shortcut isolation. Exact build, signing and distribution results are appended to the published release after artifact verification.

Clean-account browser/Finder installation, Keychain allow/deny, a full Sparkle install/relaunch cycle, and runtime on minimum macOS 12.0 have not been reverified for this release. The stable designation does not change these testing limits.
