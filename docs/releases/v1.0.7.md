# Hive 1.0.7 — Antigravity commit messages and quieter agent startup

## What's new

- Antigravity CLI (`agy`) can generate commit messages from staged changes. Select it in Settings → Git and optionally set `--model` and `--effort`. Hive uses the CLI's existing sign-in and sends the prompt through stdin, with tool actions denied.
- Antigravity's sign-in check at startup no longer creates an attention notification. Questions during a working turn still request attention; an idle prompt after a completed turn preserves unread status without sending another notification.

Stable release for macOS on Apple Silicon. Existing settings and workspaces remain compatible; no migration is required. Antigravity generation was checked with `agy` 1.5.3.

## Verification and limits

Local formatting, Clippy with warnings denied, 546 Rust tests, 26 Python tests, dependency/license checks, secret scans, and the core/GPUI boundary passed. Three existing opt-in tests remain outside the default suite.

Regression tests cover Antigravity generator availability, allowed arguments, successful and failed or incomplete responses, malformed JSON, and saved settings compatibility. Agent-status tests cover startup sign-in checks, questions during a turn, repeated reports, and unread status after a completed turn. An isolated native debug build confirmed the Antigravity picker entry and argument hint; a real `agy` smoke test generated a commit message from a synthetic prompt.

Not repeated: clean-account installation, macOS 12 runtime, a full Sparkle install/relaunch, Keychain allow/deny, older Antigravity CLI versions, and live notification delivery for these status transitions. Finish active agent sessions before an update restarts Hive.
