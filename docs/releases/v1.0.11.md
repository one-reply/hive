# Hive 1.0.11 — Smooth terminal cursor blinking

## What's new

- The active terminal cursor now fades gently while blinking and lights up immediately when you type, paste, or focus the terminal.
- Blinking stops after about ten seconds of inactivity to keep idle rendering quiet. Unfocused terminals, inactive windows, Reduce Motion, and programs that request a steady or hidden cursor keep the cursor steady or hidden as appropriate.

Stable release for macOS on Apple Silicon. Existing settings and workspaces remain compatible; no migration is required.

## Verification and limits

Formatting, Clippy with warnings denied, Rust and Python tests, the core/GPUI dependency boundary, and CI dependency, license and secret checks are required before publication. Regression tests cover cursor styles and visibility, scrolling out of view, fade steps, typing, focus, window activation, Reduce Motion, exited sessions, idle timeout, and session replacement.

The existing isolated cursor QA app was inspected on macOS: the terminal and its steady idle cursor rendered. Native input automation did not affect the QA window, so interactive fade/focus checks remain unverified on screen; their transitions are covered by deterministic GPUI tests. Not repeated for this patch: clean-account installation, macOS 12 runtime, Keychain allow/deny, and a full Sparkle install/relaunch. Finish active agent sessions before an update restarts Hive.
