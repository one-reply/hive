# Hive 1.0.49 — Edit the full Git merge result

## What's new

- Click anywhere in the center Result pane to edit the full file. Select across conflicts, edit shared lines, and use a full-height editor with line numbers, syntax highlighting, and soft wrapping.
- Accept either side or both for each conflict. Undo and Redo restore both text and resolution choices. Mark Resolved writes and stages the complete edited file.

On macOS, an isolated Hive profile was used to accept both sides of a conflict, type inside a long wrapped paragraph, undo and redo the edit, and change the final shared line. The working file and Git index matched the expected bytes, including the missing trailing newline. Automated tests also cover BOM and CRLF preservation.
