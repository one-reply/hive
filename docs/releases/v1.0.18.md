# Hive 1.0.18 — Inline Git blame and editor polish

## What's new

- See who last changed the line under your cursor, with an author and age annotation. Hover for commit details or click to open the commit in Git History.
- Inline blame follows unsaved edits, preserves CRLF and UTF-8 BOM encoding, discards stale results, and limits Git work to one request per document. Toggle it in Settings → Files.
- Read search matches more clearly in dark themes.
- Expand and collapse Git hosting server settings with a smooth transition.
- Updated SVG rendering and JavaScript parsing dependencies.

## Verification and limits

Release checks cover formatting, Clippy with warnings denied, workspace tests, Python packaging tests, security and licenses, Linux helpers for both architectures, and the GPUI-free hive-core boundary. Distribution requires Developer ID signing, Apple notarization, a stapled ticket, Gatekeeper acceptance, and verified Sparkle signatures and downloaded release assets.

Regression coverage includes blame parsing, CRLF/BOM buffers, stale request ordering, setting compatibility, annotation placement and fade transitions. A clean macOS user profile, macOS 12 runtime, live SSH authentication, and a full Sparkle install/relaunch have not been rechecked for this release.

Stable release for macOS on Apple Silicon.
