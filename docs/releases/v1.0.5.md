# Hive 1.0.5 — Terminal scrolling and notification permissions

- Dragging a terminal selection beyond a pane now sends wheel events to applications with mouse reporting, allowing TUI applications such as Codex to scroll their own history. Shell scrollback keeps its existing behavior. Autoscroll stops when the session exits.
- Settings → Terminal warns when macOS blocks Hive's agent notifications and offers a button to open System Settings. Permission refreshes when returning to Hive settings.

Stable release for macOS on Apple Silicon. Existing settings and workspaces remain compatible; no migration is required. Update through Hive → Check for Updates, or download the release archive and checksum.

## Verification and limits

Rust regression tests cover wheel direction and bounds, disabled mouse reporting, no arrow-key fallback, stopping autoscroll on process exit, and notification authorization status. Formatting, Clippy, Rust/Python tests, dependency/security checks and release verification are recorded below after completion.

A TUI may clear its selection when it redraws; selection across multiple application screens is not guaranteed. Native sustained drag in real Codex is not verified: the automation tool releases the mouse at the drag endpoint. The isolated debug app and mouse-report fixture started, but a short automated drag did not confirm scrolling.

Not repeated: clean-account installation, macOS 12 runtime, a full Sparkle install/relaunch, notification deny/allow and navigation in the signed package, and paid agent turns. Finish active agent sessions before an update restarts Hive.
