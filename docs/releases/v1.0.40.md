# Hive 1.0.40 — More flexible pipeline recipes

## What's new

- Drag stages from the palette onto the recipe canvas, reorder existing stages and resize the stage inspector.
- Place reviews side by side to run them in parallel. Each review shows its own findings, and the group shares a repair round.
- Run a review only when changed files match its configured paths. Recipes without a shared contract can also approve plans automatically.
- Hold Space in the new run's task field to dictate, then release it to transcribe. Dictation settings show whether dictation is ready and let you preview its prompt.

## Verification

The release requires passing integration CI, Apple notarization, Gatekeeper validation and Sparkle signature checks. Manual verification is recorded with the published release.
