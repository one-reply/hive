# Hive 1.0.43 — Faster editing and Git review

## What's new

- Review changes for a worktree in one scrollable Files changed tab. Selecting a file in the Git panel takes you to its patch. Staged and unstaged changes remain individually selectable.
- The Files panel stays responsive after large deletions. Rebuilding a directory with 4,000 files and 2,000 deletions took 5.6 ms in testing, down from 560 ms.
- Typing in large TypeScript files is faster. In a 32,000-line file, 95% of measured insertions finished within 1.7 ms, down from 20 ms. Hive also uses less temporary memory when checking for unsaved changes in files with Windows line endings.
- Closing the last focused editor releases its buffer and undo history. A separate fix releases font descriptors allocated by macOS.
- The editor has more room for code. Right-click the file tab to adjust indentation, or press ⌃G to jump to a line and column.

## Verification

Native Apple Silicon testing covered repeated file, diff and terminal opens and closes, large-file editing and four concurrent terminals. macOS reported zero leaked bytes before and after 300 cycles. All 339 observed child processes exited. The workspace passed 1,869 tests. The performance audit did not cover overnight sessions or live agent services.
