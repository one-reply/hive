# Hive 0.1.5 — Update reminders and release highlights

## What's new

- See a compact card in the bottom-right corner when a newer compatible version is available. Hive checks on launch and daily using Sparkle's signed update feed.
- Open the standard updater with the right-aligned Update button. You choose when to download, install, and restart.
- Read What's New after launching a different installed version. Highlights are bundled with Hive and work offline; the card appears once per version change, including the first launch with this feature.
- Reopen highlights from Settings → Updates → What's New, or follow Full release notes to the exact installed release. View Releases still opens the complete history.
- Keep working while update reminders are visible. Automatic checks respect Sparkle's opt-out and skipped versions.

## Installation and compatibility

- macOS on Apple Silicon only; Intel Macs are unsupported.
- Update through Hive → Check for Updates, or use the signed archive attached to this release once it is available.
- Existing settings and projects are preserved. Older state files without a release-highlights marker remain compatible.
- Finish active agent sessions before installing an update that restarts Hive.

## Verification and publication

The GitHub draft records the exact build commit, CI results, Developer ID and
notarization checks, and remaining installation checks. Publication requires the
final archive to pass signature, ticket, checksum and clean-profile installation
checks. A development build or an older version's notarization does not verify
this release.
