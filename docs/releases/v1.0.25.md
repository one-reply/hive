# Hive 1.0.25 — Discard Git changes by group

## What's new

- Use the rollback button beside **Stage all** in **Changes** to discard unstaged edits across the group. Hive restores tracked files from the Git index and preserves staged edits.
- Use the trash button beside **Stage all** in **Untracked** to permanently delete the group's untracked files.
- Confirm each group action once. The dialog shows the worktree and affected file count and flags files hidden by the filter. Hive checks that each selected path still belongs to the confirmed group before applying the action.

## Verification

Regression tests cover partially staged files, deleted tracked files, literal filenames, ignored files, stale selections, and replacement directories. The macOS development app was used to check both controls and open and dismiss the discard dialog. Mutation behavior was verified by tests against temporary repositories.
