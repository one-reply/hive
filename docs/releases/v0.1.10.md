# Hive 0.1.10 — Smoother terminals, lighter background work

## What's new

- Scrolling a Claude Code or Codex conversation in a terminal tab follows the trackpad at the display's refresh rate instead of stuttering. Typed characters and agent output appear without the previous 16 ms delay.
- Terminals draw busy output with less work and far less memory: each character is shaped once and reused across frames, and the terminal is no longer locked while text is prepared. Rendering looks exactly the same.
- Agent spinners in collapsed projects and folded agent strips no longer keep the window redrawing.
- Pull request status is no longer polled while Hive is in the background, and the Files panel skips a duplicate refresh when Git reports no changes.

## Installation and compatibility

- macOS on Apple Silicon only; Intel Macs are unsupported.
- Update through Hive → Check for Updates, or download the signed archive attached to this release.
- Existing projects, workspaces and settings remain compatible. No settings or saved data change.
- Finish active agent sessions before installing an update that restarts Hive.

## Verification

Automated coverage includes the terminal glyph cache (font variants, blank and combining
cells, decorations, reuse, font changes and its size bound) and the sidebar collapse timing.
A pixel comparison of a terminal fixture with styles, colours, box drawing, CJK, emoji and
combining marks showed no difference from 0.1.9 for Menlo and JetBrains Mono. Under a
full-screen redraw test, CPU fell from 4.5% to 3.2% and memory footprint from 669 MB to
232 MB. The published release records its exact build commit, CI results, signature and
notarization checks, and unverified installation scenarios below.
