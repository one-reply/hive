# Hive 0.1.4 — Agent restoration and safer terminal closing

This release includes the changes on `main` since 0.1.3.

## What's new

- Restore supported agent conversations when reopening saved terminals, and add Antigravity support.
- Find active Codex conversations from rollout files, including versions that no longer keep thread-writer locks open.
- Deliver resize signals correctly to agents running in PTY terminals.
- Ask before closing a terminal pane or tab with a running agent. The confirmation is enabled by default and can be changed in Settings → Terminal.
- Drag selected files from the Files navigator into terminal input.
- Use the new `one-reply/hive` repository and working update-feed address after the repository transfer.

## Installation and compatibility

- macOS on Apple Silicon only; Intel Macs are unsupported.
- Download `Hive-0.1.4-macos-arm64.zip` and its `.sha256` file from the release assets.
  Verify with `shasum -a 256 -c Hive-0.1.4-macos-arm64.zip.sha256`, extract the ZIP,
  and move Hive.app to Applications.
- Conversation restoration resumes supported agent sessions; it does not restore arbitrary running shell processes.
- The bundle's minimum macOS version does not establish that every supported OS version has been tested.

## Verification and publication

The GitHub draft records the exact build commit, CI results, Developer ID and
notarization checks, and any remaining installation checks. Publication requires
the final ZIP to pass signature, ticket, checksum and clean-profile installation
checks. Approval of an older Hive version does not notarize this version.
