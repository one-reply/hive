# Hive 1.0.44 — Selected project in the sidebar

## What's new

- A line in the project's accent color marks the selected project and its worktrees in the sidebar. The line stays visible when the project is collapsed and fades as the selection changes.

## Verification

Sidebar regression tests cover selection changes and collapsed project groups. The previous release's full Sparkle installation and relaunch test was for 1.0.43.
