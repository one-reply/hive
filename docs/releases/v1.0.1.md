# Hive 1.0.1 — Quicker editor and terminal controls

## What's new

- **Tab accepts code suggestions.** When the completion menu is open, Tab inserts the selected suggestion. With the menu dismissed, Tab continues to indent normally.
- **Right-click a terminal pane** for Copy, Paste, Split Right, Split Down, and Close Pane. Actions target the clicked pane; Copy is disabled when nothing is selected.
- **Jump straight to Git or Files** with Command-Shift-G and Command-Shift-E. These shortcuts open the right sidebar if it is hidden and are also available in the View menu and shortcut settings.
- **Keep track of the active project when collapsed.** Its header now carries the selection highlight while its worktree cards are hidden.

## Installation and compatibility

- Stable release for macOS on Apple Silicon only.
- Update through **Hive → Check for Updates**, or download the signed archive and SHA-256 checksum attached to this release.
- Existing projects, workspaces and settings remain compatible. No data migration is required.
- Finish active agent sessions before installing an update that restarts Hive.

## Verification

New GPUI window tests exercise Tab accepting a suggestion and normal indentation after Escape. Shortcut tests detect conflicting defaults, alongside the existing workspace and terminal tests. The GPUI test-support dependency is enabled only for development tests.

Exact build, native smoke, signing and distribution results are appended to the published release after artifact verification. Clean-account browser/Finder installation, Keychain allow/deny, a full Sparkle install/relaunch cycle, and runtime on minimum macOS 12.0 have not been reverified for this release.
