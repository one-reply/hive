# Hive 1.0.35 — Clearer pipeline review decisions

## What's new

- When a run reaches its repair limit, see review findings, failed checks, and the repair round above the decision controls. Each choice explains what happens next. Open the Checks tab for full command output.
- Drag templates to change their order in the shared pipeline library.
- Long review findings wrap, and expanded timeline details stay visible.

## Verification

Release checks cover formatting, Clippy, workspace tests, licenses, both Linux helpers, and Apple Silicon packaging. Distribution checks cover Developer ID, Apple notarization, Gatekeeper, the archive checksum, and both Sparkle signatures.

Interactive repair-limit decisions, paid-agent runs, and a full Sparkle installation and relaunch are outside this release's verification scope.
