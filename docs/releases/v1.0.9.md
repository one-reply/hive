# Hive 1.0.9 — Lighter while agents work, and keyboard focus between panes

## What's new

- Hive uses about half the CPU while an agent works and the window sits idle. The Working indicator in the sidebar now turns in steps instead of redrawing the window on every display refresh, agent detection reads the process table from the system instead of running `ps` every 800 ms, and running `git`, `gh` and `ssh` commands are waited on without constant wakeups. In a test profile with 15 projects, CPU fell from 21–29% to about 12%.
- Move between the panes of a terminal tab with ⌘←, ⌘→, ⌘↑ and ⌘↓. Focus goes to the pane on that side, following the sizes you dragged the splits to. The shortcuts can be reassigned in Settings → Shortcuts.
- The focused pane among several now glows inward from its edges, light on a dark theme and dark on a light one.
- Pull request cards stop asking GitHub every minute about worktrees that have no GitHub remote: a failing check is retried ever more rarely, up to every 30 minutes.
- ⌘Q no longer stays refused after a window is closed while Hive asks about unsaved changes.
- A crash now records its cause in `~/.hive/logs/hive.log`, and an out-of-range date in a usage response or a sign-in token no longer brings Hive down.

Stable release for macOS on Apple Silicon. Existing settings and workspaces remain compatible; no migration is required.

## Changed behavior

- An agent started by another user (for example `sudo node …/claude`) is recognized by its process name only; `sudo claude` is still detected.
- After `gh auth login` or adding a GitHub remote, a pull request card that was failing can take up to 30 minutes to refresh. Switching the branch refreshes it at once.

## Verification and limits

Local formatting, Clippy with warnings denied, 636 Rust tests, 26 Python tests, and the core/GPUI boundary passed; dependency, license and secret checks passed in CI. Three existing opt-in tests remain outside the default suite.

Automated checks cover the stepped indicator's timing and that it stops when it is not shown, reading process arguments on captured samples and against the running system, command output, input, limits and cancellation, the pull request retry schedule, pane neighbors in rows, grids and resized splits, and where the new shortcuts apply. CPU was measured on a release build with an isolated profile and one agent reporting that it works.

Not checked on screen: the look of the stepped indicator and of the pane glow, the new shortcuts pressed in a running window, Reduce Motion, and ⌘Q with a window closed during the prompt. Not repeated: clean-account installation, macOS 12 runtime, a full Sparkle install/relaunch, and Keychain allow/deny. One sidebar redraw is still costly with many projects, which is why CPU halves rather than falling further. Finish active agent sessions before an update restarts Hive.
