# Hive 0.1.2 — Pick up where you left off

Hive now remembers your workspace when you quit and restores it on the next launch.

## What's new

- Restore the selected project and Git worktree.
- Reopen terminal and Git diff tabs in their saved order, with the active tab selected.
- Restore nested terminal splits, their sizes, and the active pane.
- Start fresh shells in their last known working directories, including changes made with `cd`.
- Keep a separate saved workspace for each project; other projects reopen when selected.
- Preserve closed tabs and deliberately empty workspaces.
- Skip unavailable local folders and unsupported saved tab types while keeping the remaining layout.
- Group Appearance, Shortcuts, and Updates together under Application in Settings.

## Compatibility and limits

- Existing settings and project lists remain compatible; no manual migration is needed.
- Terminal commands, running agents, conversations, and scrollback are not resumed. Restored terminals start new shells.
- Shell directories are sampled once per second; quitting immediately after `cd` can retain the previous directory.
- This release targets macOS on Apple Silicon. Intel, Linux, and Windows builds are not included.

## Verification

The implementation passed 173 Rust tests, formatting, Clippy with warnings denied,
and the check that `hive-core` has no GPUI dependency. Two opt-in tests requiring
real CLI credentials or an unlocked Keychain were excluded from the default run.
Native QA on macOS 27.2 covered workspace relaunch, tabs, nested splits, saved sizes
and focus, directory changes, active diff restoration, and closed-tab persistence.
