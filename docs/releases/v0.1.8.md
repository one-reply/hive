# Hive 0.1.8 — Six themes, one workspace

## What's new

- Appearance now has palette cards with color previews, a clear selection outline and a checkmark. Font and scrollbar settings are grouped into separate sections, with controls that wrap on narrower windows.
- Four new palettes join Hive Light and Hive Dark: One Light, Solarized Light, One Dark and Dracula. Each palette covers the interface, editor, diffs and terminal.
- Choose a light theme and a dark theme independently. System switches between your saved choices with macOS; choosing a palette keeps your current System, Light or Dark mode.
- Theme changes apply across open windows immediately. Your fonts, sizes and scrollbar preferences stay in place, and terminal applications retain control of the colors they set themselves.

## Installation and compatibility

- macOS on Apple Silicon only; Intel Macs are unsupported.
- Update through Hive → Check for Updates, or download the signed archive attached to this release.
- Existing settings, projects and workspaces remain compatible. Older settings use Hive Light and Hive Dark; an invalid new theme preference falls back independently without resetting other settings.
- Finish active agent sessions before installing an update that restarts Hive.

## Verification

Automated coverage includes old settings, invalid theme preferences, independent
light/dark selection, saved-state restoration, all six embedded palettes and all
36 palette transitions without leftover colors. The original Hive JSX highlighting
regressions remain covered.

All six palettes, mode selection, saved preferences, font-size Reset and the
880×600 Appearance window were checked in an isolated development profile. The main
window and terminal also received the selected palette. Keyboard navigation,
scrolling, 640×420 and the complete editor/diff/terminal matrix across two windows
were not fully verified because the native automation tool could not reliably
control the windows.
