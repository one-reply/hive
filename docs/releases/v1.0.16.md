# Hive 1.0.16 — Remember project expansion

Projects now restore a useful sidebar state on launch. Your manual expand/collapse choice takes priority. Otherwise, the last selected project and projects with saved open tabs are expanded; inactive projects stay collapsed. Terminal, file, diff, and agent-resume tabs count as saved work.

Background activity does not change expansion while you work. Disclosure clicks save without rescanning Git. Removing and re-adding a project clears its old choice. Existing state files load with the new automatic default; no migration is required.

## Verification and limits

693 Rust tests passed (3 existing opt-in tests ignored), together with formatting, Clippy with warnings denied, and the core/GPUI dependency boundary. Core tests cover startup policy, manual priority, host isolation, removal/re-addition, old or malformed preferences, and persistence roundtrips. GPUI tests cover selection, disclosure clicks, saved choices, and removal/re-addition. Independent review found no remaining blocker.

An isolated native app verified five startup cases and retained manual choices after quitting and relaunching. Live SSH reconnect, agent Resume, macOS 12 runtime, and a full Sparkle install/relaunch were not rechecked.

Stable release for macOS on Apple Silicon.
