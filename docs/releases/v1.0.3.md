# Hive 1.0.3 — Clearer notifications and quieter usage indicators

## What's new

- **More informative attention notifications.** The bell shows each session's status, task title, agent, project or worktree, and branch. SSH sessions also identify their host. Search includes this context, and long titles remain available on hover.
- **Compact usage indicators.** Provider icons and usage bars replace repeated names. Hover for every usage window and reset time. Unavailable limits use a gray icon and empty gray bar, with the error or sign-in instructions in the hover card.
- **Clearer Hive Dark dividers.** Slightly brighter separators make panels and tabs easier to distinguish.
- **Reliable diff closing.** Command-W closes empty Git diffs and diffs showing a read error, including when an open diff becomes empty after a refresh.
- **Updated documentation.** The README describes the current workflow and includes new captures of the running application without automation controls or sharing overlays.

## Installation and compatibility

- Stable release for macOS on Apple Silicon only.
- Update through **Hive → Check for Updates**, or download the signed archive and SHA-256 checksum attached to this release.
- Existing projects, workspaces, and settings remain compatible. No data migration is required.
- Finish active agent sessions before installing an update that restarts Hive.

## Verification

Formatting, Clippy with warnings denied, 521 Rust tests (three existing opt-in tests ignored), 26 Python tests, security/license checks, and the core/GPUI dependency boundary passed locally. Regression coverage includes attention context and search, empty results, unavailable usage and recovery, and keyboard dispatch across normal, empty, and failed diffs.

Native checks in isolated development profiles covered notification layout, searching, keyboard navigation and session selection; compact usage indicators, hover details and accessibility descriptions; and Command-W closing empty, failed, refreshed, and ordinary diffs and a file editor.

The release follows the existing local Xcode Developer ID signing and Apple notarization route while hosted Apple API credentials are unavailable. Exact CI, signature, artifact, and distribution checks are recorded in the published notes.

Not reverified for this release: a full paid multi-agent turn, clean-account browser/Finder installation, Keychain allow/deny, the complete Sparkle install/relaunch cycle, and runtime on minimum macOS 12.0. SSH notification context, missing usage data, and usage recovery are covered by automated tests rather than new live sessions.
