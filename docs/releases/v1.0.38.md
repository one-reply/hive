# Hive 1.0.38 — Project avatars and workflow stage icons

## What's new

- The **Avatar** tab in project settings offers ten illustrated badges for the sidebar and tabs, alongside the project initial.
- Pick from sixteen preset emoji or enter your own in the **Emoji** tab. Presets display in full and apply with one click.
- The workflow editor's **Add stage** menu uses the same role icons as the workflow canvas for all five stage choices.

## Verification

The project badge picker and the Add stage menu were checked in Hive on macOS. The checks covered the illustrated avatar palette, emoji rendering, badge persistence, and the five stage icons. A complete Sparkle install and relaunch was outside these feature checks.
