# Hive 1.0.6 — SSH restoration and sidebar fixes

## What's new

- Folders without a Git repository now show a quiet empty Git panel with an unavailable Git tab. Git polling stops for these folders on both local and SSH hosts. After initializing Git, switch projects and return to detect the repository.
- Restored SSH terminal panes automatically open new shells in their saved directories when you first enter the project after restarting Hive. Previous agent commands are not replayed.
- Clicking the agent strip in an inactive worktree card selects that project and worktree. Expanding and collapsing the strip works only in the selected card.

Stable release for macOS on Apple Silicon. Existing settings and workspaces remain compatible; no migration is required.

## Verification and limits

Regression tests cover missing-repository error classification, stopped Git polling and preserved drafts, and actual GPUI click propagation from an inactive agent strip. An inverted selection guard is rejected by the click regression test. Native debug checks confirmed the Git empty state and automatic SSH shell restoration on an existing host.

Not repeated: clean-account installation, macOS 12 runtime, a full Sparkle install/relaunch, Keychain allow/deny, and paid agent turns. Native manual agent-strip clicking could not be confirmed because the UI automation returned inconsistent window state; the GPUI mouse-event regression passed. Finish active agent sessions before an update restarts Hive.
