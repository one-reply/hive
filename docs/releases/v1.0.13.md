# Hive 1.0.13 — Project switching and update checks

## What's new

- Click a project's name to switch to it immediately. A separate, always-visible arrow on the right collapses or expands its worktrees without changing the active project.
- Clicking the active project's name keeps its selected worktree. Switching to another project selects its primary worktree, or the folder itself for a plain folder.
- Check for Updates now opens Sparkle directly without opening Settings or changing its selected page. Update results, download and installation continue in Sparkle's native windows.
- If the updater is starting or unavailable, Hive shows a separate explanation. If all Hive windows are closed, an unavailable-updater message opens with the main window.

Stable release for macOS on Apple Silicon. Existing settings and workspaces remain compatible; no migration is required.

## Verification and limits

Regression tests cover project selection by host and path, folders and removed projects, preserving the current worktree, independent selection and folding, keyboard activation, updater startup/unavailable errors, and alerts without an active window. Formatting, Clippy with warnings denied, 681 Rust tests, 26 Python tests, dependency/license checks, and the history secret scan passed; three existing opt-in tests remain ignored. A mutation of the host/path guard was caught by the selection regression test.

An isolated debug app with disposable Git repositories verified switching expanded projects by name, folding and unfolding without switching, the selected collapsed header, and preserving a feature worktree. Separate native updater checks verified the up-to-date result, the available-update prompt, the Settings button, preserving Appearance during a menu check, and the missing-framework message.

Not repeated for this release: a clean macOS account installation, macOS 12 runtime, Keychain allow/deny, native drag-and-drop, and a full Sparkle download/install/relaunch. SSH selection is covered without a real SSH connection. Finish active agent sessions before an update restarts Hive.
