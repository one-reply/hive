# Hive 1.0.12 — Search in file contents

## What's new

- Search file contents across your local project from the Files panel's new Content tab, or press ⌘⇧F.
- Match case, whole words, or regular expressions. Results stream in file order with highlighted previews and line numbers; click a match to open its location in the editor.
- Browse results with the arrow keys, collapse file groups, and press Enter to open a match. Press Enter in the search field or refresh to pick up files changed by agents.
- Editor Replace now uses ⌥⌘F; ⌘P continues to search file names.

Stable release for macOS on Apple Silicon. Existing settings and workspaces remain compatible; no migration is required.

## Verification and limits

Content search reads saved UTF-8 text files up to 1 MiB, respects Git ignore rules, and skips binary files and symlinks. It searches up to 100,000 files and shows up to 5,000 matching lines, with a notice when results are limited. SSH projects and unsaved editor buffers are not searched. Empty regex matches are omitted; a match spanning multiple lines is shown on its first line.

Regression coverage includes Unicode and CRLF positions, BOM, matching options, invalid expressions, unsupported files, result ordering and limits, cancellation, stale results, keyboard navigation and shortcut precedence. Local formatting, Clippy with warnings denied, 677 Rust tests, 26 Python tests, dependency/license checks, the core/GPUI boundary, and the history secret scan passed. Three existing opt-in Rust tests are ignored. Reversing case sensitivity was caught by the matching-options regression test. A single file exceeding 5,000 matching lines now correctly reports that results are limited.

An isolated debug app launched on macOS and its accessibility tree showed the Content tab, query field, matching controls and status. Native input automation did not change the query, so interactive results, highlighting and editor focus remain unverified on screen.

Not repeated for this release: clean-account installation, macOS 12 runtime, Keychain allow/deny, and a full Sparkle install/relaunch. Finish active agent sessions before an update restarts Hive.
